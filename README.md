# Макет «Центр поддержки и заявок» (ЦПиЗ)

Кликабельный прототип интерфейса по файлу `TZ_DIPLOM.md`. Чистый HTML + CSS + JavaScript,
без сборки, зависимостей и серверной части. Все данные, сотрудники и документы — вымышленные.

## Как открыть

Двойной клик по `index.html` (Chrome / Edge / Яндекс.Браузер). Сервер не нужен.

## Публикация на GitHub Pages

Макет полностью статический, поэтому публикуется как есть, без сборки:
репозиторий отдаётся целиком из корня ветки `main`.

Адрес страницы: <https://kaelth4s.github.io/ikbfu-thesis-site/>

Настройка (один раз): **Settings → Pages → Source: Deploy from a branch → Branch: `main`,
папка `/ (root)` → Save**. После первого сохранения сайт появляется в течение минуты,
а последующие изменения подхватываются автоматически после `git push`.

Редактор внешнего вида на опубликованной странице работает так же, но настройки сохраняются
в `localStorage` **того браузера**, в котором вы их меняли (адрес Pages — обычный `https`,
поэтому хранилище доступно). Чтобы показать свою версию вида другому человеку, используйте
в редакторе кнопку «Скачать HTML» — получится файл с уже вшитыми настройками.

## Режим редактирования вида

Кнопка **«Редактировать вид»** в шапке открывает панель справа.

* Вкладка **«Тема»** — глобальные настройки: цвет кнопок и ссылок, цвет текста, фон страницы и карточек,
  размер шрифта, ширина контента, скругления, высота и ширина кнопок, жирность и расположение кнопок.
  Есть готовые темы: Светлая, Тёмная, Вузовская классика, Мягкая зелёная.
* Вкладка **«Элемент»** — кликните по любому месту страницы: выбирается **самый вложенный** элемент
  под курсором, поэтому можно править текст заголовка, подписи или значения в списке, а не только
  карточку целиком. Доступны фон, цвет текста и рамки, размер шрифта, отступы, скругление, ширина,
  тень, выравнивание, сдвиг, порядок в списке и текст.

  Навигация по вложенности: блок **«Родительские блоки»** поднимает выбор на карточку или секцию,
  кнопка «Выбрать родителя» — на один уровень вверх, а у составного блока в разделе «Текст» есть
  кнопки его дочерних элементов — чтобы сразу перейти к нужному. Текст правится у элемента
  без вложенных блоков; если блок составной, редактор подскажет, какой подэлемент выбрать.

Пока режим включён, ссылки не переходят — вместо этого выбирается элемент для правки.
`Esc` снимает выбор.

## Как сохраняются изменения

1. **Автосохранение** — настройки пишутся в `localStorage` браузера и применяются при следующем
   открытии `index.html`. Кнопка «Сбросить всё» возвращает исходный вид.
2. **«Экспорт» / «Импорт»** — файл `cpiaz-mockup-settings.json` с настройками: можно перенести вид
   на другой компьютер или в другой браузер.
3. **«Скачать HTML»** — ещё одна копия `index.html` с уже вшитыми настройками: положите её
   в папку `mockup` вместо исходного файла, и вид сохранится даже там, где `localStorage`
   недоступен. Удобно, чтобы отдать преподавателю один файл «как выглядит у меня».

Если браузер блокирует `localStorage` (например, при открытии из некоторых менеджеров файлов),
панель напишет «браузер блокирует автосохранение» — тогда используйте «Скачать HTML» или «Экспорт».

## Границы макета

Формы, фильтры, кнопки и конструктор только имитируют поведение: показывают уведомление
и меняют вид, но не отправляют данные и не сохраняют заявки. Реальная логика, БД, интеграции
и разграничение прав относятся к этапу реализации из раздела 5 ТЗ.
