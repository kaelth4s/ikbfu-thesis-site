# Версии сайта-прототипа

## v2.0 — 2026-11-01

Перестройка в три части с оболочкой-переключателем.

- `flows/` — схемы процессов перевода: четыре процедуры, две зоны «Сейчас» и «С системой»,
  блоки со стрелками, раскрытие по этапам, точки зрения «Сверху / Студент / Сотрудник»,
  панель деталей по клику, редактирование и экспорт/импорт JSON.
- `mockup/` — новый минималистичный макет «Центра поддержки и заявок» по четырём реальным
  обращениям: каналы документов (ИС / запрос подразделению / загрузка студента / бумажный
  оригинал), автопроверки, запросы подразделениям, история, паспорт и СНИЛС из ИС.
- `legacy-mockup/` — прежний прототип разделов ТЗ, перенесён без изменений.
- Корневой `index.html` — оболочка с переключателем режимов и запоминанием выбора.

## v1.0 — 2026-10-10

Кликабельный макет «Центра поддержки и заявок» по концептуальному ТЗ: каталог заявок,
подача, тикеты, панели администратора, конструктор заявок, роли, метрики, аудит,
визуальный редактор вида.
